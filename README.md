# Everlong Development

Website for Everlong Development, a real estate development company working at the intersection of land, capital and execution.

## Development

Requires Node.js 22+ and a package manager (npm, pnpm, or bun).

```sh
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

## Stack

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- GSAP
